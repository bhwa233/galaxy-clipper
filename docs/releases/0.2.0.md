# 0.2.0 · 流程化界面、字幕处理与命令行

- 按流程操作：左侧改为 ① 素材 → ② 字幕 → ③ AI 选片 → ④ 草稿 → ⑤ 封面（可跳过）→ ⑥ 导出 六个步骤，条件不满足的步骤置灰并说明原因，属性栏底部固定“下一步”。
- 平台字幕：从原视频链接只获取字幕文件（不下载媒体），按设置的字幕语言，每种语言优先人工字幕，可选自动字幕；导入时从媒体元数据自动带出链接。该能力自 Galaxy Downloader 0.8.0 迁入。
- 字幕页：字幕轨卡片（语言、人工 / 自动 / 识别 / 文件、条数），预览上实时叠加所选风格的字幕，预览下方的编辑条可把起点 / 终点设为当前播放位置，“生成真实帧”按实际烧录方式核对效果。
- 导出页：左侧配置、中间预览、右侧导出与导出记录。支持原片字幕文件、原片视频（不带 / 当前轨 / 中英双语，烧录或软字幕，软字幕含中文、英文、中英双语三条轨）、草稿成片和封面。
- 风格库：内置 5 种字幕风格与 5 种封面风格，可复制后自定义参数并实时预览；所有项目共用，删除自定义风格时使用处退回其基础风格。预览、原片烧录与草稿成片使用同一套字幕参数。
- 命令行 `clipper`：通过本机控制通道驱动客户端，覆盖导入、字幕、选片、草稿、导出和风格查询；`--json` 输出单个 JSON 对象，退出码区分失败、缺少前置条件和无法连接。设置中可开关“命令行与 Agent”。

这是未经签名的开发预览版。`pnpm check`、真实 Electron 客户端界面探针与 CLI 端到端探针已通过；AI 选片、草稿与封面的完整操作需要云端文字模型配置，尚未实测；安装版的命令注册未在各平台实机验证。详见 `docs/test-links.md`。

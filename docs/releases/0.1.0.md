# 0.1.0 · Galaxy Clipper 开发预览

首个独立剪辑客户端源码与跨平台安装包预览。

- 三栏工作台：左侧素材与工具、中央视频预览、右侧对象属性。
- 项目数据独立保存；原视频默认只引用。提供旧项目、字幕、候选、草稿及本地模型的显式导入能力。
- 包含本地转写、云端 AI 候选、多草稿、预览、成片及封面导出的实现。服务密钥由客户端独立保存。

这是未经签名的开发预览版。`pnpm check`、Windows NSIS 本地构建与真实 Electron 启动探针已通过；当前课程素材的完整剪辑流程、远端转写和云端服务尚未完成实测。详见 `docs/test-links.md`。

# 0.2.1 · 封面与导出体验改进

本次预览包含尚未单独发布的 0.2.0 更新：六步剪辑工作区、平台字幕获取、共用风格库、统一导出页，以及本地 `clipper` 命令行。

- 修复 Windows 偶发封面生成超时；独立生成或随成片导出都可输出 JPEG。新增八种封面布局，保存当前草稿的封面配置后，封面步骤即打勾。
- 原片视频默认用当前 AI 草稿标题命名，仍导出完整原片；原片和成片导出记录都可在应用内预览、打开文件所在位置。
- 成片烧录字幕自动分页，每屏最多两行，不改动原始字幕和独立字幕文件。
- 设置采用左侧分类导航；字幕页显示转写和模型准备阶段，支持分别取消下载与转写、重试下载或导入已有模型。
- 修复切换编辑步骤时旧面板残留的问题。

这是未签名的开发预览。Windows 开发版已验证封面生成、导出和模型准备等流程；本次未验证远端 ASR 或各平台安装后的运行。详见 `docs/test-links.md`。
